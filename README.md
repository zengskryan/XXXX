# Unity 游戏开发学习笔记

本仓库包含 Unity 游戏客户端开发的学习笔记与知识整理，涵盖图形学、Shader 编程、性能优化、网络通信等多个方面。

## 内容概览

### 学习任务清单（XXXX.md）

整理了 Unity 游戏客户端开发需要掌握的核心知识点，包括：

- **网络通信**：HTTP/TCP/UDP、帧同步与状态同步、Protobuf/MsgPack 协议
- **资源管理**：资源更新与下载策略、AssetBundle 加载方式、内存占用与缓存策略
- **性能优化**：内存优化、纹理压缩、GC 优化、UGUI 优化
- **软件设计模式**：常见设计模式及其在游戏开发中的应用
- **图形学**：渲染流程、Shader 编程、常用游戏效果实现
- **数学**：向量与矩阵运算、游戏中的常用数学计算
- **算法与数据结构**：LeetCode 练习、游戏中常用的算法与数据结构
- **编程语言**：C#、Lua、编译原理与运行时环境
