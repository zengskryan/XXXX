### Unity Shader 入门精要笔记

基于《Unity Shader入门精要》一书的详细读书笔记，覆盖以下章节：

| 章节 | 标题 | 主要内容 |
|------|------|----------|
| 第2章 | 渲染流水线 | 应用阶段、几何阶段、光栅化阶段三大流程；CPU 与 GPU 通信机制；GPU 流水线各阶段（顶点着色器、裁剪、屏幕映射、三角形设置与遍历、片元着色器、逐片元操作）；DrawCall 原理与优化；OpenGL/DirectX 与着色语言（HLSL、GLSL、CG） |
| 第3章 | Unity Shader 基础 | ShaderLab 语法结构；Properties 属性块；SubShader 与 Pass 语义块；渲染状态与标签设置；表面着色器、顶点/片元着色器、固定函数着色器的区别与选择；Fallback 机制 |
| 第4章 | Shader 所需的数学基础 | 笛卡尔坐标系（左手/右手）；矢量运算（点积、叉积及几何意义）；矩阵运算（乘法、转置、逆矩阵、正交矩阵）；齐次坐标与仿射变换；平移、缩放、旋转矩阵；坐标空间变换（模型→世界→观察→裁剪→屏幕）；Unity 内置变换矩阵与摄像机参数 |
| 第5章 | 开始 Unity Shader 学习之旅 | 顶点/片元着色器基本结构与语义（POSITION、SV_POSITION 等）；Unity 内置包含文件（UnityCG.cginc 等）与内置变量；CG/HLSL 语义详解；Shader 调试方法（假彩色、帧调试器）；渲染平台差异处理；数值精度（float/half/fixed）与编码规范 |
| 第6章 | Unity 中的基础光照 | 光照物理基础（辐照度、吸收与散射、BRDF）；标准光照模型四部分（环境光、自发光、漫反射、高光反射）；兰伯特漫反射模型实现；Phong 与 Blinn-Phong 高光反射模型实现；逐顶点与逐像素光照对比 |
| 第7章 | 基础纹理 | 纹理映射与纹理坐标；单张纹理采样与滤波模式（Point/Bilinear/Trilinear）；凹凸映射（高度纹理与法线纹理、切线空间 vs 模型空间）；渐变纹理实现卡通化效果；遮罩纹理控制高光细节 |
| 第8章 | 透明效果 | 透明度测试（clip 函数）与透明度混合；深度缓冲与渲染顺序问题；Unity 渲染队列（Background/Geometry/AlphaTest/Transparent/Overlay）；Blend 混合命令；开启深度写入的半透明效果 |
| 第9章 | 更复杂的光照 | 渲染路径详解（前向渲染、顶点照明、延迟渲染）；前向渲染 Base Pass 与 Additional Pass 机制；延迟渲染 G-buffer 原理；光源类型（平行光、点光源、聚光灯）与衰减；Shadow Map 阴影技术；屏幕空间阴影映射；透明物体阴影处理 |
| 第10章 | 高级纹理 | 立方体纹理与环境映射（天空盒、反射、折射）；渲染纹理（Render Texture）与 GrabPass；镜子效果与玻璃折射效果实现；程序纹理生成 |
| 第11章 | 让画面动起来 | 内置时间变量（\_Time 等）；纹理动画（序列帧动画、无限滚动背景）；顶点动画（河流波动、广告牌技术）；顶点动画的批处理与阴影注意事项 |
| 第12章 | 屏幕后处理效果 | 屏幕后处理脚本系统（OnRenderImage、Graphics.Blit）；亮度/饱和度/对比度调整；边缘检测（卷积算子）；高斯模糊；Bloom 全屏泛光效果；运动模糊 |
| 第13章 | 使用深度和法线纹理 | 基于深度纹理重建世界空间位置；全局雾效实现 |
| 第14章 | 非真实感渲染 | 卡通风格渲染：基于色调的着色、轮廓线渲染、卡通高光 |
| 第15章 | 使用噪声 | 噪声纹理原理；消融效果（dissolve）实现；水波效果模拟 |
| 第16章 | Unity 中的渲染优化技术 | 移动平台 GPU 特点；CPU/GPU/带宽瓶颈分析；渲染分析工具（Stats、Profiler、FrameDebugger）；动态批处理与静态批处理原理及限制；减少顶点数（几何体优化、LOD、遮挡剔除）；减少片元数（渲染队列控制、透明物体优化、烘焙光照）；纹理压缩与 Mipmap；Shader LOD 技术 |
| 第17章 | Unity 的表面着色器探秘 | 表面着色器作为顶点/片元着色器的高层抽象；表面着色器的编译原理与实际使用 |
| 第18章 | 基于物理的渲染 | PBS（Physically Based Shading）概述；与传统经验模型（Lambert、Phong、Blinn-Phong）的对比；Unity 内置 PBS 工具使用 |

配套的 **ShaderLearn** Unity 工程包含笔记中涉及的 Shader 代码实践。
